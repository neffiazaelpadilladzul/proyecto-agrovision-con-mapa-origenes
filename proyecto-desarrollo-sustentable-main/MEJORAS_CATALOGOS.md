# Mejora de presentación de catálogos

Se unificó la presentación de los catálogos de Ganadería, Comercio, Industria, Servicios y Producción Artesanal con el estilo de referencia de Agricultura.

## Cambios realizados
- Se coloca el catálogo destacado al inicio de cada módulo, antes del panel de análisis.
- Se aplica el mismo ancho de ficha, bordes redondeados, espaciado y jerarquía de título.
- Se adapta la ficha a pantallas pequeñas.
- Se conservan los textos, indicadores, datos y funciones particulares de cada sector.
- Se conserva la carpeta `.backup_original` con la versión original del proyecto.

Los cambios se encuentran en `js/funciones.js` y `css/estilos.css`.
